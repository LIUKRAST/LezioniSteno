# Il lag infernale di propants

Il portatile di propants sta cercando di caricare i chunk su minecraft, ma la frequenza è bloccata a 6FPS.
Stampa un messaggio per ogni frame renderizzato da 1 a 6 per incoraggiarlo!

## Attenzione
Hai direttamente una funzione main, senza tester. Scrivi il ciclo e usa
```java
System.out.println("");
```
per scrivere in console!
Ricorda che puoi usare le somme con le stringhe
`"a" + "b" = "ab"` e puoi anche sommare gli int
```java
int a = 1;
String testo = "Ciao "; // con lo spazio alla fine!

String totale = testo + a; // "Ciao 1"
```

Nel ciclo puoi fare ad esempio
```java
System.out.println("Conto " + i); // "Conto 0" al primo ciclo
```
