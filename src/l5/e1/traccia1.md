# Concatenazione di array di string
Simile al precedente, ma invece di avere due sole stringhe ne abbiamo un'array. Quindi una lista di testi (una lista di liste di caratteri).

Se l'array ha grandezza 0, si deve ritornare null, altrimenti si fa la concatenazione di tutte le stringhe

_Attenzione, anche l'array può essere nulla!_

```java
if(arr == null) return null;
```
