# Il livello di caffeina
Prima di iniziare a programmare sul suo sito web, Propants controlla quante tazzine di caffè ha bevuto.

Per avere la carica giusta, deve prendere esattamente una tazza di caffè. Se ne prende due o più, è troppo carico, altrimenti è troppo stanco.

Quando la carica è giusta, ritorna `Propants ha la carica giusta!`
Quando la carica è bassa, ritorna `Propants dorme in piedi...`
Quando la carica è troppa, ritorna `ATTENZIONE: Propants fa esplodere tutto!`

# Stringhe

Attenzione, qui incontriamo un concetto nuovo, che vedremo nella prossima lezione: le stringhe (testo).

Puoi tranquillamente creare una variabile stringa così (non ti scordare della maiuscola)

```java
String a = "ciao!";
```

Puoi ovviamente fare il return 
```java
return "Ciao!";
```
